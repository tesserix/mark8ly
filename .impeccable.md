# Mark8ly Design Guidelines

## Design Context

### Users
Mark8ly serves merchants across the spectrum — from indie/SMB founders setting up their first online store, to established mid-market brands migrating off Shopify/WooCommerce. The design must feel approachable enough for a first-timer mid-onboarding, yet credible enough that an established retailer trusts it with their catalog. Primary jobs-to-be-done: (1) onboard a new store with minimum friction, (2) manage products/orders confidently in admin, (3) present a branded storefront customers want to buy from.

### Brand Personality
**Calm, premium, refined.** Editorial in spirit — closer to a thoughtfully designed independent magazine than a dev tool or DTC hype brand. The voice is confident without shouting. Interfaces should evoke trust, craft, and quiet competence — never urgency, novelty, or hustle.

### Aesthetic Direction
- **Theme:** Light mode only. Modern editorial luxury — Bottega Veneta / Phoebe Philo / Aesop territory. Tokens live in `packages/ui/src/styles/mark8ly-tokens.css` and are imported by every app.
- **Palette: Paper · Ink · Moss.**
  - **Paper** (`--paper-*`, canonical bg `#F7F6F2`) — warm-neutral off-white. Less yellow than bone, more body than pure white. The "expensive paper" cue. Pure white `#FFFFFF` is reserved for elevated surfaces (cards, popovers) where the hairline contrast against paper creates the elevation.
  - **Ink** (`--ink-*`, canonical fg `#0E0E0C`) — near-black with almost zero warmth. Sharp, fashion-magazine ink. This is the primary CTA color, not moss.
  - **Moss** (`--moss-*`, canonical accent `#2D4A2B`) — one decisive editorial green, used sparingly for links, focus rings, key CTA hover, and functional success. Never decorative. This is the *only* accent.
  - **Functional only:** `--signal` vermillion for genuine urgency, `--danger` oxblood for errors, `--warning` amber-bronze for warnings. Never used for decoration.
- **No more terracotta, sage, cream, or amber.** Legacy `--warm-*` / `--terracotta-*` / `--sage-*` Tailwind utilities still exist but they now alias to paper/ink/moss for back-compat. Migrate as you touch files.
- **Typography:** Source Serif 4 for editorial display/headlines, Source Sans 3 for UI/body. Fluid type scale via `--text-*` tokens (clamp-based). Use the serif deliberately — it carries the brand more than the color does.
- **Surface:** Crisp paper background, hairline rules between sections (not bordered cards), generous whitespace, `text-wrap: balance` on headings. Single-elevation shadow scale (`--shadow-1/2/3`).
- **Radius:** 6px default, 4–24px scale. Editorial layouts prefer crisp edges over heavy rounding.
- **Motion:** One easing curve (`--ease-out`, ease-out-expo), three durations (fast/base/slow). Reserve motion for entrances and one orchestrated load reveal — never on hover-lift bounce.

**Anti-references — explicitly avoid:**
- Generic SaaS (Stripe/Linear clones) — no cool-blue geometric dev-tool look
- Loud DTC (Gymshark/Glossier) — no oversized hype type, neon gradients, marketing-speak
- Enterprise dashboards — no dense, gray, utilitarian admin panels
- Web3/AI maximalism — no dark mode, glow effects, glassmorphism, or "intelligence" theatrics

### Accessibility
WCAG 2.1 AA is the baseline floor for every surface:
- Contrast ratios verified against the warm palette (terracotta on cream needs care — check 4.5:1 for text)
- Full keyboard navigation; visible `:focus-visible` ring already defined
- `prefers-reduced-motion` honored (already wired in `globals.css`)
- Semantic HTML, proper labels, screen-reader-friendly form errors

### Design Principles
1. **Editorial over utilitarian** — every screen should feel composed, not assembled. Whitespace, type hierarchy, and rhythm matter as much as functionality. Hairline rules between sections, not bordered cards.
2. **Paper, ink, one accent** — paper background, ink text and primary CTA, moss for links/focus/key moments. Never introduce a fourth color for decoration.
3. **Confidence through restraint** — one accent per view, generous spacing, minimal chrome, no glassmorphism, no hover-lift bounce. If it feels loud, it's wrong.
4. **Serif carries the brand** — use Source Serif 4 deliberately for headlines, numerals, and key editorial moments; don't waste it on body copy. The serif does the work color used to do.
5. **Trust the system** — use the Mark8ly tokens from `@repo/ui/styles/mark8ly-tokens.css` and the `@tesserix/web` form primitives (Path C). Don't invent new colors, radii, shadows, or motion per feature. New brand-level building blocks go into `@repo/ui` so admin and storefront can reuse them.
6. **Asymmetric, never centered** — left-aligned text, asymmetric grids, varied vertical rhythm. Centered hero blocks and same-sized card grids are AI slop tells we explicitly reject.
